# Wanted: US public procurement notices (SAM.gov + state portals) normalised daily

_Category: `industry-reference`_

**What**
notice id, source portal, agency, title, type (RFP/RFQ/sources sought/award), NAICS, PSC, set-aside, posted date, response deadline, place of performance, contact (official capacity), attachments URLs, snapshot date.

**Task it serves**
"Find every open federal or Texas solicitation under NAICS 541511 due in the next 14 days."

**Coverage and freshness**
SAM.gov plus the ten largest state portals; daily.

**Rights a buyer needs**
Public notices; declare each portal's terms. Redistribution needed.

**Format**
JSONL per day plus CSV.

**Where a seller could start**
SAM.gov opportunities API and state portal exports.

**Why this is on the board**
Sales and bid agents need one schema across portals.

---
Seeded by Graunt from what agents ask this plugin for; not yet requested by a named buyer. A 👍 or a comment saying you need it turns it into real demand.

**To claim it:** comment `claiming`. **To list it:** `/prepare-packet <path>` in Claude Code with the [Graunt plugin](https://github.com/Grauntketplace/graunt-plugin), or upload at https://graunt.com/prepare. Listing is free; the first listing that meets this spec is featured in the plugin's `/find-data` results and this repository's README.
