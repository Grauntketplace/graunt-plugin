# Wanted: State statute section-level text snapshots (CA, NY, TX, FL) with citations and hashes

_Category: `legal-regulatory`_

**What**
state, code, title/chapter, section, heading, plain text (no publisher annotations), effective date, legislative source URL, sha256, snapshot date.

**Task it serves**
"Quote Cal. Bus. & Prof. Code § 1680 exactly and tell me when it last changed."

**Coverage and freshness**
CA, NY, TX, FL first; quarterly, or per legislative session.

**Rights a buyer needs**
Only the state-published text; no publisher annotations or headnotes. Declare each state's terms; several states assert no copyright in statutory text, some do not say.

**Format**
JSONL per state code plus CSV index.

**Where a seller could start**
Official legislature sites (leginfo.legislature.ca.gov, nysenate.gov, statutes.capitol.texas.gov, leg.state.fl.us). Read each site's terms and declare them.

**Why this is on the board**
Legal and compliance agents need exact text with provenance; the official sites are hard to query at section granularity.
