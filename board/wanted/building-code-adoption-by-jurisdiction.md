# Wanted: Building code adoption by US jurisdiction: IBC, IRC, IECC, NEC editions, amendments and effective dates

_Category: `legal-regulatory`_

**What**
jurisdiction (state/county/city), code family, model edition adopted, effective date, local amendments reference and URL, enforcing authority, source URL, verified date.

**Task it serves**
"Which IECC edition applies to a new commercial build in Boise as of today, and are there local amendments?"

**Coverage and freshness**
All states plus the 200 largest cities and counties; quarterly.

**Rights a buyer needs**
Compiled from public adoption ordinances. Model code text is copyrighted and out of scope. Redistribution needed.

**Format**
CSV.

**Where a seller could start**
State building-code agencies, municipal codes, ICC adoption maps (check terms).

**Why this is on the board**
Construction and insurance agents guess at editions today.
