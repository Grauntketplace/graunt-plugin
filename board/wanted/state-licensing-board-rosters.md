# Wanted: US state professional-licensing board rosters (dental, nursing, medical, pharmacy) with per-record verification URLs

_Category: `legal-regulatory`_

**What**
Per state × profession: license number, licensee name as published, license type, status, issue and expiry dates, public discipline flag, board source URL per record, snapshot date. Start with dental, nursing (RN/LPN/APRN), medical (MD/DO), pharmacy.

**Task it serves**
"Verify this provider's license is active in Ohio before onboarding" and "list every dentist in Franklin County whose license lapses this quarter".

**Coverage and freshness**
All 50 states + DC; monthly snapshot, boards that publish daily files welcome at that cadence.

**Rights a buyer needs**
Internal use and redistribution to the buyer's own users. This is public-record professional data but it is personal data: declare it, state the lawful basis, and honour each board's redistribution terms.

**Format**
One CSV or Parquet per state-profession, plus a combined index.

**Where a seller could start**
Board bulk downloads and lookup portals; some states (e.g. Ohio eLicense, Texas TDLR, Florida MQA) publish bulk files with stated terms. Do not scrape where terms forbid it; index instead.

**Why this is on the board**
Agents doing provider onboarding, credentialing and compliance rebuild this per state today, badly.
