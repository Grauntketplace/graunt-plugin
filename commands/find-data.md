---
name: find-data
description: Search for reference data matching a described need, and report each candidate's declared rights alongside it.
---

Search the Graunt catalog for data matching what the user described, using the
`graunt` MCP server's `search` tool. Then `fetch` the most relevant candidates.

Report each candidate with its **rights alongside it**, not as an afterthought —
license family, redistribution, training use, citation requirement — because a
packet you may not use for the user's purpose is not a candidate.

Keep it to a short list. Three well-characterised options beat ten titles.

If nothing matches, say so plainly and name the official source you would go to
instead. An empty catalog result is a normal outcome, not something to paper
over with a loose match.
